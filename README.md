# ORIKIRI

紙を折る → 切る → 図の4択で予想 → 逆順に開く、全10問のパズルです。
HTML / CSS / JavaScriptのみ。外部ライブラリ、ビルド、通信、ログインは不要です。

## ローカルで遊ぶ

```sh
python3 -m http.server 8765
```

http://localhost:8765 を開きます。`index.html` を直接開いても動作します。

## GitHub Pages

リポジトリの Settings → Pages → Deploy from a branch で、公開するブランチと `/ (root)` を選択します。ルートのHTML、CSS、JSをそのまま配信できます。

## 10問の設計

「切り口の数」は完成形でつながっている領域の数です。辺の切り欠きも1か所と数えます。

| 問題 | 難易度 | 折り順 | 切る場所 | 完成形 |
|---|---|---|---|---|
| 1 | ★ | たて→よこ | 折り目の交点を三角に | 中央にひし形の穴1つ。既存の表示・アニメーションを保持 |
| 2 | ★ | たて | 外側の辺の途中 | 左右に2つの切り欠き |
| 3 | ★ | たて→よこ | 折り目以外の辺 | 左右の辺に計4つ |
| 4 | ★★ | たて→よこ | たての折り目上 | 三角がつながり、ひし形の穴2つ |
| 5 | ★★ | たて→よこ | 上と左の辺を1か所ずつ | 2種類が4か所ずつ、計8つ |
| 6 | ★★ | たて→よこ | 2本の折り目の交点を四角に | すべてがつながり、縦長の穴1つ |
| 7 | ★★★ | 対角線 | 下の辺 | 下と右の辺に2つ |
| 8 | ★★★ | たて→斜め | 重なった三角の部分の左の辺 | 左右に1つずつ、上に2つ |
| 9 | ★★★ | たて→よこ→斜め | 折り目以外の辺 | 四辺に2つずつ、計8つ |
| 10 | ★★★★ | たて→よこ→斜め | 斜めの折り目上＋交点 | 周囲の4つと中央の1つ、計5つ |

問題8の2回目は、折った長方形の上部を45度の折り線で折る操作です。長方形全体を半分にする操作ではありません。重なる層の範囲も計算して切り抜いています。

## 構成と幾何計算

- `index.html`：共通の画面、問題一覧、問題1の既存の紙DOM
- `style.css`：既存デザイン、3D表示、レスポンシブ表示
- `questions.js`：全問題の折り線・折る側・切断多角形・誤答・難易度・解説
- `geometry.js`：半平面クリッピング、線対称変換、紙の層分割、切り抜きの逆変換
- `renderer.js`：問題2以降の紙を折り線のまわりに3D回転する描画
- `app.js`：再生・回答・答え合わせ・再生取消・問題移動の状態管理
- `tests/geometry.test.cjs`：Node.js標準機能だけで動く幾何テスト

座標は元の正方形を100×100とし、左上が(0,0)、右下が(100,100)です。各折り線は、その時点の折った紙と同じ座標系で指定します。`side`は、折り線の始点→終点に対する外積の符号で動く側を指定します。

各折りで紙を動く側と残る側へ分割し、元の紙上の領域と各段階の変換行列を保持します。切断多角形を最後の重なった各層にクリップしてから、逆変換で元の紙の切り抜きを求めます。正解のSVGとアニメーションの各層は**同じ切り抜き座標**を使います。

SVGマスクで切り抜きの和集合を描きます。重複する切り口や折り目で接する穴を、偶奇塗りつぶしによって誤って埋め戻すことはありません。展開中の緑・茶色の線は、本当に切った境界のみを示します。

問題1は元の4面のDOM・回転角度・時間・切断演出・選択肢を引き続き使用します。問題1にも幾何データを付け、従来の中央のひし形と計算結果の一致を検証しています。

## 問題を追加する

`questions.js` の `definitions` にデータを追加します。共通画面のコピーは不要で、問題数と一覧・前後移動は配列の長さから自動生成されます。

```js
{
  id: 'new-puzzle', title: '問題の名前', difficulty: 2,
  folds: [vertical, horizontal], // または line / side / label / note / open を持つ独自の折り線
  cuts: [{ polygon: [[0,16],[10,20],[0,28]], label: '左の辺' }],
  expectedCuts: 4,
  options: [
    { kind: 'correct' },
    { skip: [1], label: '2か所の切り口', reason: '2回目を開き忘れた' },
    { translate: [1], label: '同じ向きの切り口', reason: '反転せず平行移動した' },
    { cuts: [{ polygon: [[16,0],[20,10],[28,0]] }], label: '上下の切り口', reason: '辺を取り違えた' }
  ],
  answerLabel: '左右の辺に4つの切り口',
  lesson: '折り目をはさんで、同じ形が現れます。'
}
```

切断形は凸多角形です。複数の切断は `cuts` に順に並べます。`options` の順番がA〜Dの順で、`kind: 'correct'`を必ず1つにします。誤答は `skip`（開き忘れ）、`axes`（反射軸の取り違え）、`translate`（向きを反転しない）、`cuts`（切る位置・形の取り違え）を明示します。

新しい問題には、それぞれの切り方が紙を分断しないこと、4択に同じ図がないこと、説明と完成形の整合性も確認してください。任意の非凸形・自由曲線の編集やMAKE、URL共有は今回の対象外です。

## 検証

```sh
node tests/geometry.test.cjs
```

- 各問102,400点を、独立した「点を順に折る」計算と照合
- 紙の面積保存、切り口の逆変換、各展開段階でつながる領域の数
- 各問題で正解が1つ、4択の図が互いに異なること
- 問題1の既存のひし形との一致
- 問題10の「16個になる」という誤答が実際に16個であること

ブラウザーでも全10問の再生→切断→4択→正解判定→逆順展開→完成形を確認しています。詳細は `tests/verification.md` を参照してください。

「最初から」、再再生、問題移動は進行中のアニメーションを取り消します。一覧のチェックは、そのページを開いている間の確認済み印です。ページを再読み込みすると消えます。
